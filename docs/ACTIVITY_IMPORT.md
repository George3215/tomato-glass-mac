# 补记接口（JSON v1）

统计页面只显示已记录活动。未记录时段仍可通过「手动补记」或本接口补充，默认不推断活动、不连接 AI 服务。

1. 选择日期，点击「补记接口」，保存 JSON 上下文。它只包含当天未记录的时间区间、时区和填写说明，不含现有任务内容。
2. 如果愿意，将该文件与自己对活动的描述交给 AI，或自行编辑。软件不会自动发送文件。
3. AI 只能根据明确描述生成 entries，不确定的时间保持空白。
4. 点击「导入 JSON」，检查完整预览并确认。整批校验成功后才保存。

```json
{
  "version": 1,
  "source": "ai",
  "entries": [
    {
      "task": "阅读示例论文",
      "category": "学习",
      "start": "2026-09-01T14:00:00+08:00",
      "end": "2026-09-01T14:30:00+08:00"
    }
  ]
}
```

- `source`：`ai` 或 `manual`，记录中保留 AI补记 / 导入补记标记。
- `task`：非空，最多 300 个字符。
- `category`：学习、工作、休息、其他。
- 时间：带时区的 ISO 8601，精确到秒，无小数；开始早于结束，结束不晚于当前时间。
- 文件最大 1 MB，每批 1–1000 条。不得与已记录、正在计时或同批其他条目重叠。失败时整批不写入。
- `unrecorded`、`timezone`、`instructions` 是导出上下文，不作为活动导入；填写 entries 后可以保留。

给 AI 的提示词：

> 根据我明确提供的实际活动，生成番茄时光补记 JSON v1。只在提供的 unrecorded 区间内填写，不猜测遗漏时段，不生成未来或相互重叠记录。source 为 ai，分类限学习、工作、休息、其他，时间包含时区并精确到秒。信息不足时先问我，不要编造。输出前列出你所依据的事实，JSON 中仅保留确认的记录。

示例日期与任务仅用于说明；请替换为自己的实际记录。
