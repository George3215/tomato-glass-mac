# 1.5.1 渲染优化记录

- 复用 NSBitmapImageRep 和 NSImage，避免每帧生成 CGImage/NSImage。
- 动态背景直接绘制模拟结果，省去被覆盖的原图与渐变绘制。
- 动态状态未变化时不重建模拟器。
- 隐藏、关闭、最小化或完全遮挡窗口时释放模拟器和像素缓冲；重新显示时按需重建。
- 保留 30 Hz 水波模拟、原始清晰度和计时功能。

一次本机微基准：macOS 15.5 / Apple Silicon，Swift `-O`，760×570 视图，120 帧，逐帧 autoreleasepool。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 模拟与渲染计算耗时 | 0.492 s | 0.405 s |
| 进程最大 RSS | 46,088,192 B | 43,614,208 B |

该基准仅包含壁纸加载和 RippleWater.advance，不包含完整应用、窗口合成或常驻菜单栏；单次测量有噪声，不代表实际应用内存下降比例。内存变化的确定性依据是复用帧对象，以及隐藏时置空渲染器；实际使用量由系统缓存、壁纸尺寸和窗口状态决定。
